# Soirée Planner

A simple web app for planning a three-night summer soirée.

## Features

- **Guest list** — name, RSVP status, and plus-one for each invitee
- **Signature drink menu** — one cocktail and one mocktail per night
- **Golden hour countdown** — live timer to opening night at 8:12 PM

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure and sections |
| `styles.css` | Summer dusk theme and string-light styling |
| `app.js` | Guest data, drink menu, and countdown logic |
